iPhone experiment

Share Sheet test

Try opening the iOS Share Sheet directly from a webpage, then install this separate test as a Home Screen web app.

Step 1 — Try the Share Sheet

Press the button to open the native iPhone sharing options for this page.

Can't see Add to Home Screen? This website-triggered Share Sheet may not offer installation. Instead, use Safari's own Share button, then choose Add to Home Screen and enable Open as Web App.

Step 2 — Launch the new Home Screen icon. There you'll see Load HTML so you can choose a file from Files. Your existing HTML viewer is unaffected.

Home Screen app

Load an HTML file

Choose a self-contained HTML file from Files. It will be stored on this device and reopen automatically from this Home Screen icon.

Step 3 — Select the HTML

This happens after installation, so there is no need to transfer a file from Safari.
